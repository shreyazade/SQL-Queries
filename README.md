# SQL Practice for QA Engineers

## Project Overview
This repository contains SQL queries designed specifically for QA Engineers.
It focuses on real-world testing scenarios such as data validation, bug reproduction,
and complex SQL queries used in backend testing.

## Database Context
Sample E-commerce database with tables:
- users
- orders
- order_items
- products
- payments

## Topics Covered
- Joins (INNER, LEFT)
- Subqueries
- Window Functions
- Data validation queries
- Bug reproduction using SQL

## QA Scenarios Covered
- Identifying data mismatches
- Verifying business logic
- Finding duplicates and missing records
- Validating calculations
- Reproducing production bugs

## Why This Repo?
- Demonstrates strong SQL skills
- Shows testing mindset, not just querying
- Useful for interviews and real projects

QA Engineer with 3+ years of experience in Automation, API, and Database Testing
